# JOB-IMPACT: AI Impact Analysis on Employment

A comprehensive data analysis project investigating the impact of artificial intelligence on various job sectors and industries.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Jupyter Notebook](https://img.shields.io/badge/Jupyter-Notebook-orange.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## 📋 Project Overview

This repository contains an in-depth analysis of how AI technologies are affecting employment across different industries, job roles, and regions. The project combines data analysis, visualization, and machine learning techniques to identify trends and patterns.

## 📊 Key Features

- **Data Analysis**: Comprehensive exploratory data analysis (EDA) of job market trends
- **Visualizations**: Interactive and static visualizations of AI impact metrics
- **Machine Learning**: Predictive models for job impact assessment
- **Model Comparison**: Performance metrics for multiple ML models
- **Data-Driven Insights**: Clear, actionable conclusions from the analysis

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- pip package manager
- Jupyter Notebook

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sarpelpalu/JOB-IMPACT.git
   cd JOB-IMPACT
   ```

2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

5. **Open and run**
   - Navigate to `notebooks/AI Impact on job.ipynb`
   - Run all cells or execute step-by-step
